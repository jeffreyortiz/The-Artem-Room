    Card payments (Stripe)

    1. Make a free account at stripe.com and add the bank account deposits should go to.
    2. In Stripe go to Developers → API keys and copy the Secret key (starts with sk_live_). Want to try it first? Turn on Test mode and use the sk_test_ key — test card 4242 4242 4242 4242.
    3. Paste it here. Payment confirmations get set up automatically.
